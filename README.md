# 杭州九龙山庄（瀛洲苑）及周边别墅 · 租售行情调研页

一个纯静态、零构建的交互式数据展示页，收录 **2026-10-31** 采集的杭州富阳银湖「九龙山庄（含瀛洲苑组团）」及周边近郊别墅小区的挂牌价、租金与历史行情数据。

## 内容

- **总览**：核心 KPI、各平台价格口径对比、近郊别墅均价横评、一句话结论
- **九龙山庄·瀛洲苑**：历史价格走势（别墅口径 vs 全小区口径）、在售挂牌明细、在租明细与租金分布、法拍记录、瀛洲苑组团调研说明
- **周边别墅对比**：银湖/之江/闲林/良渚/青山湖/湘湖 20 个小区对比（可按板块筛选、表头排序）
- **租金行情**：15 个整租样本对比（面积 × 租金散点）
- **市场背景**：杭州各区/富阳各板块均价、行情要点
- **数据说明**：来源、口径、方法与免责声明

## 本地预览

```bash
cd 本目录
python3 -m http.server 8000
# 打开 http://localhost:8000
```

> 注意：页面通过 fetch 加载 `data/*.json`，请务必通过 HTTP 服务访问，直接双击 index.html 会因 file:// CORS 限制加载失败。

## 部署到 Vercel

**方式一：网页拖拽（最快，无需命令行）**
1. 打开 https://vercel.com/new
2. 将本目录拖入部署区域（或先推送到 GitHub 后选择仓库）
3. Framework Preset 选 **Other**，无需任何构建命令，点击 Deploy

**方式二：Vercel CLI**
```bash
npm i -g vercel
cd 本目录
vercel --prod
```

**方式三：GitHub 自动部署**
1. 将本目录推送到 GitHub 仓库
2. 在 vercel.com/new 导入该仓库，直接部署（零配置）

也可部署到 GitHub Pages / Netlify / 任意静态托管。

## 目录结构

```
├── index.html              # 交互页面（ECharts via CDN）
├── vercel.json             # Vercel 配置
├── README.md
└── data/
    ├── metadata.json       # 采集元信息/来源/方法/免责声明
    ├── jiulong.json        # 九龙山庄：价格口径、走势、在售、在租、法拍
    ├── villas-compare.json # 周边对比小区与租金样本
    └── market.json         # 杭州市场背景
```

## 数据口径提示

- 「别墅口径」与「全小区混合口径」（含洋房/公寓）差异很大（九龙山庄约 4.5 万 vs 3.1 万），页面中始终分开呈现；
- 挂牌价 ≠ 成交价，法拍成交可视为底部价格参照；
- 贝壳/链家的逐套明细（含瀛洲苑组团房源定位）需登录后采集，数据结构已预留，登录贝壳后可随时补充 `data/jiulong.json`。
